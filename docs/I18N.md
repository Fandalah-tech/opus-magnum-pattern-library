# Localization

English is the canonical language for source code, identifiers, documentation, and structured catalogue content.

## Runtime module

`data/i18n.js` contains:

- the default locale;
- supported locale codes;
- UI message dictionaries;
- `OpusI18n.t(key)`;
- `OpusI18n.setLocale(locale)`;
- locale persistence through `localStorage`;
- an `opus:localechange` event.

HTML strings use `data-i18n` or `data-i18n-placeholder` attributes.

## Adding a language

1. Add the locale code to `supportedLocales`.
2. Add a message dictionary under `messages`.
3. Add the language to the selector in `index.html`.
4. Add localized catalogue content in a separate locale file when entity translation is introduced.

## Canonical content rule

Domain identifiers and canonical content remain English. Translations are presentation overlays and must never alter stable IDs, relation IDs, metric keys, or source evidence.

## Current limitation

The first localization pass translates the interface. Canonical catalogue content is English. A later pass will add entity-level translation dictionaries for names, summaries, descriptions, principles, and notes.
