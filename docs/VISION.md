# Vision – Opus Magnum Pattern Library

## Mission
Construire une base de connaissances structurée sur les patterns d'Opus Magnum afin de servir de fondation à un futur moteur d'analyse, de génération d'architectures et éventuellement à un solveur assisté par IA.

## Phases
1. Banque de patterns.
2. Outil d'exploration HTML.
3. Formalisation des heuristiques.
4. Générateur d'architectures.
5. Solveur.
6. IA.

## Principe
Le projet ne cherche pas d'abord à résoudre les puzzles, mais à comprendre les mécanismes réutilisables qui composent les solutions des meilleurs joueurs.
