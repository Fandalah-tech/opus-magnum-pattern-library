# Terminology policy

The project uses English as its canonical development and data language.

## Status values

Every domain term should eventually carry one of these statuses:

- `official`: visible in the game or official Zachtronics material;
- `community`: broadly attested in established community resources;
- `provisional`: introduced by this research project and subject to revision;
- `deprecated`: retained only for migration or historical reference.

## Provisional research vocabulary

The following current catalogue names are useful descriptive labels, but are not claimed to be official or community-standard terms:

- Single Projection
- Double Projection
- Shared Axis
- Timed Handoff
- Loop Buffer
- Mirror Assembler
- Shared Motion
- Handoff
- Buffer Decoupling
- Exploitable Symmetry

They must carry `termStatus: 'provisional'` until evidence supports promotion to `community`, or until replaced by a better term.

## Sources and evidence

Terminology evidence should be recorded as source URLs or source identifiers in future structured data. A later terminology registry will make this machine-readable.

Current validation references:

- Opus Magnum Wiki — Elements
- Opus Magnum Wiki — Glyphs
- Opus Magnum Wiki — Theoretical Best and puzzle metric tables

The wiki is a community source, not an official Zachtronics specification. Therefore, terms clearly visible in the game are treated as official, while pattern taxonomy found only in community material should be treated as community terminology unless independently verified.
