# OpusJS Atom Master Model

Pb is the validated geometry reference for all seven metal atoms.

## Shared geometry

All metal atoms inherit the same holder, casing, ring, core and rivet geometry. Metal-specific rendering may vary only through:

- core palette and material response;
- alchemical symbol;
- optical symbol size and offset;
- restrained element-specific highlights.

## Validated Pb baseline

- holder radius: 28.0
- outer casing radius: 24.0
- bevel radius: 22.65
- inner casing radius: 20.15
- core radius: 18.7
- inner ring radius: 16.05
- rivet orbit: 21.15
- rivet radius: 0.42

Pb is considered visually approved after the final optical symbol centering pass in OpusJS 0.6.0.
