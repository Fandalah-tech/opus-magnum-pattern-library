# Arm Groups V1

A shared arm hub may expose exactly 2, 3, or 6 canonical branches.

- One MasterHexBaseV1 per mechanism.
- One central hub and one upright length label.
- Every branch uses the same MasterArmV1 geometry and thickness.
- Branch directions remain canonical multiples of 60 degrees.
- Branches attach through reinforced collars around the shared hub.
- No duplicated hub, base, or label is rendered for grouped arms.
