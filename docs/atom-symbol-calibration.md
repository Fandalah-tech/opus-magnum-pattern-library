# Atom symbol calibration

OpusJS 0.8.2 normalizes the seven canonical atom symbols by optical size rather than by identical font-size values. All atoms continue to use `masterAtomV1` and `masterMaterialV1`; only identity-level symbol size and vertical offset vary.

The Mercury reference crop is aligned to the far-right sprite of the current comparison atlas. The atlas remains a provisional external reference and should be replaced if a cleaner canonical Mercury capture becomes available.
