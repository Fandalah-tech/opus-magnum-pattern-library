STRICT HELD-OUT TRIPLEX COMPONENT GRAPH - OM2021_W1

Status
------
The solver still does not solve OM2021_W1 without examples from that puzzle.
This milestone fixes the physical representation error identified by the
previous benchmark: fragment repairs now move one shared donor component
instead of creating duplicate copies of the same part.

It also adds target-aware replay progress. The local engine can now distinguish
an idle survivor from a candidate that actually removes a bond, duplicates an
atom, or creates a prism bond. A two-front search portfolio retains both
mechanically stable and chemically active candidates for the next hybrid
geometry-and-timing stage.

Target-aware chemical progress
------------------------------
Every local replay now records event counts, manipulation counts, chemistry
event kinds, and the subset required by the target manufacturing plan. For
OM2021_W1 the required event families are bond removal, duplication, prism bond
creation/settling, and product delivery. Off-plan calcification no longer
outranks target-relevant activity.

At the same 2,187-variant budget, the local engine found distinct useful
partial chains:

- one donor family reaches bond removal;
- seven retained variants reach atom duplication plus bond creation, with five
  required chemistry events before failure;
- two retained variants reach bond removal, bond creation, and floating prism
  bond creation in one replay, with four required chemistry events before
  failure.

No single variant yet covers bond removal, duplication, prism bonding, and
delivery together. OMSim rejects the active-only retained set mechanically,
so these event chains are search guidance, not valid solutions.

Two-front repair portfolio
--------------------------
A linear score discarded either stable inactive machines or active colliding
machines. Geometric repair now reserves half of its promotion and result budget
for target-relevant progress and half for mechanical survival.

For each assembly the final experiment retained:

- 15 progress-front variants;
- 15 survival-front variants;
- four long validations selected from each objective;
- 30 nine-part layouts, with no component duplication.

Authoritative OMSim outcomes for the 90-result balanced portfolio:

- completed: 0
- no completion within the OMSim cycle limit: 23
- collision: 64
- other mechanical error: 3

The survival-only run remains the mechanically strongest result. The balanced
portfolio deliberately spends half its capacity preserving the chemically
active parents needed by the next stage.

What the solver can now do
--------------------------
The solver can now:

- retain original part and anchor identities without changing canonical hashes;
- preserve repeated occurrences of the same mechanism inside one solution;
- select the exact occurrence referenced by a coherent edge or convergence;
- merge shared input, arm, glyph, track, and output proposals by physical ID;
- move a shared component without increasing the machine's part count;
- report shared identities, raw proposals, and resolved pose conflicts;
- count replay activity and separate chemistry from mere elapsed cycles;
- score chemistry against the target manufacturing plan;
- preserve complementary survival and chemical-progress search fronts.

It cannot yet:

- combine the useful geometry from one variant with the timing from another;
- reconcile all shared-component pose constraints as a globally optimized
  rigid subgraph;
- trust local replay alone where OMSim exposes track or collision differences;
- deliver any product on the strict OM2021_W1 held-out benchmark.
