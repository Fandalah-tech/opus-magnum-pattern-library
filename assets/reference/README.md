# Reference asset policy

This directory is reserved for locally hosted visual references used by the Opus Magnum Codex.

Each imported asset must include:

- original file name;
- source page and file-page URL;
- credited author/uploader when available;
- exact license shown on the source file page;
- modification notes;
- a local fallback or removal path if the license cannot be confirmed.

Do not add an asset merely because it appears on a wiki page. Verify the individual file page first. Community page text on the Opus Magnum Wiki is generally marked CC BY-SA, but an individual image can carry a different rights notice.
